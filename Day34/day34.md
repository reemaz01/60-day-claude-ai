# 🕵️ Marketing Detective – Case Files

An interactive detective-style marketing simulation that challenges users to investigate campaign data, uncover hidden clues, and identify the strategic marketing mistake behind each business case.

Built as a **single-file HTML application** using **HTML, CSS, and Vanilla JavaScript**, the project combines marketing education with gamified problem-solving.

---

## 📌 Project Overview

Marketing Detective places the user in the role of a marketing investigator.

Each case presents a fictional company experiencing poor campaign performance. Players analyze campaign metrics, customer feedback, budget allocation, and social media data before determining the primary strategic mistake.

Rather than memorizing marketing concepts, users learn through investigation and critical thinking.

---

## ✨ Features

- 🕵️ Detective-themed interactive experience
- 📁 Confidential case file briefing
- 📌 Draggable investigation board
- 📊 Campaign metrics analysis
- 💰 Budget allocation review
- 💬 Customer feedback investigation
- 📈 Social media performance evaluation
- 🔍 Interactive clue discovery system
- ✅ Multiple-choice investigation challenge
- 📖 Detailed case explanation after every investigation
- 📚 Learning report with improvement recommendations
- 🎲 Randomized case selection for replayability
- 📱 Fully responsive design
- 🎨 Smooth animations and transitions

---

## 🎮 Gameplay

1. Open a confidential marketing case.
2. Review the client briefing.
3. Examine campaign evidence.
4. Organize evidence on the investigation board.
5. Reveal hidden clues.
6. Identify the marketing mistake.
7. Review the correct solution.
8. Learn best practices through the final report.

## 📚 What I Learned

Building **Marketing Detective** helped strengthen both my frontend development and marketing analysis skills.

### Technical Learnings

- Built a complete multi-screen application using only Vanilla JavaScript.
- Managed application state without external frameworks.
- Implemented drag-and-drop interactions for evidence cards.
- Created reusable UI components for scalable case generation.
- Improved responsive layout design and CSS animation techniques.
- Designed a fully self-contained HTML application.

### Marketing Learnings

- High reach does not always result in high conversions.
- Understanding the target audience is more valuable than chasing vanity metrics.
- Customer feedback often reveals hidden campaign issues.
- Marketing success depends on aligning audience, message, channel, and timing.
- Strong calls-to-action and clear messaging improve campaign performance.
- Data should guide strategic decisions rather than assumptions.
