# Cognitive Pattern Explorer

An interactive single-page web application that helps users explore their decision-making and thinking patterns through engaging psychological reflection exercises.

> **Disclaimer:** This application is designed for self-reflection and educational purposes only. It is **not** a psychological assessment, diagnostic tool, or substitute for professional mental health advice.

## Project Overview

Cognitive Pattern Explorer guides users through a series of interactive activities to identify common cognitive tendencies. Instead of assigning fixed personality labels, it encourages reflection by analyzing choices across multiple scenarios.

The application focuses on five thinking styles:

-  Analytical Thinker
-  Emotional Intuitive
-  Overthinking Loop
-  Action-First Decision Maker
-  Balanced Reflective Thinker

---

#  Features

### Interactive Multi-Step Journey

- Welcome screen
- Progress tracking
- Four guided chapters
- Reflection summary

### Chapter 1 — Thinking Scenarios

Users respond to realistic decision-making situations.

- Multiple-choice interactions
- Trait-based scoring
- Immediate progress validation

### Chapter 2 — Priority Sorting

Drag-and-drop exercise where users organize priorities into:

- Matters Most
- Matters Somewhat
- Matters Least

Includes:

- Mouse support
- Touch support
- Keyboard accessibility

### Chapter 3 — Thinking Timeline

Users arrange thoughts in their natural decision-making order.

Supports:

- Drag & Drop
- Keyboard navigation
- Mobile touch interactions

### Reflection Journal

After completing all chapters the application generates:

- Trait percentage breakdown
- Dominant thinking pattern
- Secondary thinking tendencies
- Personalized reflection
- Optional private journal entry

# Learning Outcomes

This project demonstrates how interactive web applications can encourage self-reflection using thoughtful UI design rather than traditional questionnaires. It combines psychology-inspired activities with accessible front-end development techniques to create an engaging user experience.

---

# Key Learnings

Building this project provided valuable experience in:

- Designing interactive multi-step user experiences.
- Implementing custom drag-and-drop functionality without external libraries.
- Creating accessible interfaces with keyboard and screen reader support.
- Developing a weighted scoring system that combines multiple interaction types.
- Managing application state using vanilla JavaScript.
- Building responsive layouts that work across devices.
- Using CSS variables to support dynamic themes and visual customization.
- Generating downloadable reports directly in the browser.
- Creating engaging educational experiences while clearly communicating application limitations.
- Structuring a complete single-file web application that remains modular and maintainable.
