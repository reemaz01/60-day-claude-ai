#  Interactive Learning Studio – Python OOP


An interactive browser-based learning platform that teaches **Object-Oriented Programming (OOP) in Python** through structured lessons, visual diagrams, coding exercises, quizzes, and a final project challenge.

---

## Project Overview

The Interactive Learning Studio transforms traditional programming tutorials into a hands-on learning experience.

Instead of reading static notes, learners progress through guided modules, complete quizzes, unlock achievements, and practice concepts using interactive exercises.

The application is built entirely using **HTML, CSS, and JavaScript** and runs directly in the browser without requiring any external libraries or frameworks.

---

## Features

-  4 structured learning modules
-  Beginner to Advanced learning path
-  Progress tracking
-  Achievement badge system
-  Dark / Light mode
-  Printable study notes
-  Interactive coding exercises
-  Instant quiz feedback
-  Progress bar
-  Final practical challenge
-  OOP cheat sheet
-  Module unlocking system
-  Responsive design
