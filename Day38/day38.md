# ⌨️ Typing Speed Studio

A modern typing practice web application focused on improving typing speed, accuracy, and consistency through interactive typing sessions and detailed analytics. The application features legal-themed typing passages, real-time performance tracking, and a comprehensive analytics dashboard.

---

## 📌 Project Overview

Typing Speed Studio is a single-page HTML application built using **HTML, CSS, and Vanilla JavaScript**. It provides users with an engaging typing experience using professionally written legal passages while tracking important typing metrics such as:

- Words Per Minute (WPM)
- Raw WPM
- Accuracy
- Typing Consistency
- Mistyped Keys
- Character Breakdown
- Session History
- Personal Best Records
- Achievement Badges

# 🚀 How to Run

1. Download the repository.
2. Open `typing-speed-studio.html` in any modern web browser.
3. Select a typing category.
4. Click **Begin Session**.
5. Complete the typing passage.
6. Review your analytics dashboard.
