# 🧭 Task Compass

An interactive organizational thinking simulator built with **HTML, CSS, and Vanilla JavaScript** that teaches users how work flows through a real organization. Players learn the difference between ownership, delegation, workflow, and collaboration by solving realistic workplace scenarios inside a café/restaurant environment.

---

# 📌 Project Overview

Task Compass is a browser-based learning application where users practice assigning responsibilities across an organization.

Instead of memorizing job roles, players learn:

- Who owns a task
- How work moves between departments
- When collaboration is necessary
- How organizational decisions affect workflow

The application uses drag-and-drop interactions, animated feedback, scoring dashboards, and reflection reports to reinforce organizational thinking.

# 🚀 Features

## Stage 1 — Ownership Challenge

Identify the primary owner responsible for resolving each workplace situation.

Examples include:

- Customer complaints
- Inventory issues
- Food safety
- Marketing requests
- Reservation mistakes

Users drag the correct role onto the task card.

---

## Stage 2 — Workflow Routing

Build the correct sequence of responsibility.

Example workflow:

```
Server
    ↓
Chef
    ↓
Restaurant Manager
```

This teaches how work travels through an organization instead of assuming one person solves everything.

---

## Stage 3 — Collaboration Challenge

Complex organizational scenarios require multiple stakeholders.

Users identify:

- Primary owner
- Supporting roles
- Communication chain
- Collaboration flow

---

## Organizational Thinking Dashboard

After completing all scenarios, Task Compass generates a performance dashboard showing:

- ✅ Ownership Score
- ✅ Delegation Score
- ✅ Collaboration Score
- ✅ Workflow Thinking Score

The dashboard also provides personalized reflections explaining strengths and improvement areas.

# 💡 Key Learnings

Building Task Compass reinforced several important organizational concepts:

- Every task should have a clearly defined owner.
- Ownership does not mean working alone—complex tasks often require collaboration.
- Efficient organizations rely on structured workflows rather than ad hoc communication.
- Assigning too many people to a task can reduce clarity and slow execution.
- Understanding communication flow is just as important as completing the task itself.
- Interactive simulations are an effective way to teach workplace decision-making and organizational thinking.
