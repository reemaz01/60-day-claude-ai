Build Your Personal Portfolio Website

Reemaz Jawed – Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my journey as a student, AI enthusiast, and creative technologist.

The website highlights my skills, projects, achievements, and ways to connect with me through an interactive and visually engaging experience.

 Features

* Responsive design for desktop, tablet, and mobile devices
* Dark and light mode support
* Smooth scrolling navigation
* Animated hero section with neural mesh background
* Typing text animation
* Reveal-on-scroll effects using Intersection Observer
* Interactive skill progress bars
* Project showcase section
* Contact section with email integration
* Social media links (GitHub and LinkedIn)
* Modern glassmorphism-inspired UI

Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Tailwind CSS (CDN)
* Google Fonts
* Local Storage API
* Intersection Observer API
* Canvas API
