#  Personal AI Playbook

> A reusable AI workflow system for building better prompts, faster.

Personal AI Playbook helps you stop rewriting prompts from scratch by turning your best AI conversations into reusable workflows. Instead of scattered notes and chat history, organize your prompts into editable templates, build custom prompts with modular blocks, and create self-improving prompt loops.

---

##  Features

###  Workflow Library

Create and reuse prompt templates for recurring tasks.

Included workflow categories:

-  Build & Code
-  Startup & Strategy
-  Build-in-Public Content

Each workflow includes:

- Editable variables
- Live prompt preview
- Example output
- Best practices
- One-click copy

---

###   Prompt Builder

Build custom prompts using reusable building blocks instead of writing free-form prompts.

Available blocks:

- Role
- Objective
- Context
- Constraints
- Reasoning Strategy
- Output Format
- Tone
- Examples
- Quality Checks

Generate structured prompts with a live preview.

---

###   Loop Builder

Turn ordinary prompts into self-improving AI workflows.

Configure:

- Goal
- Evaluation Criteria
- Improvement Strategy
- Stop Conditions
- Safety Rules

Perfect for research, writing, coding, and iterative refinement.

---

###  My Workflows

Manage your own prompt library.

Features include:

- Create workflows
- Duplicate templates
- Favorite workflows
- Import & Export
- Local browser storage

---

##  Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Storage API

No frameworks.
No backend.
No installation required.

##  Key Learnings

During development I learned:

- Reusable prompt templates dramatically reduce repetitive work.
- Structured prompts produce more consistent AI outputs.
- Modular prompt components improve maintainability.
- Self-improving prompt loops enhance response quality.
- Local storage provides a lightweight persistence layer without requiring a backend.
- Organizing workflows by category makes large prompt libraries easier to navigate.

---

##  Export Support

The application allows users to export and import their workflow library, making it easy to back up or transfer prompt collections across devices.
