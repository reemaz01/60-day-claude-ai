What is the Personal AI Playbook?

This is your personal system for working with AI — not a list of prompts to copy once, but a set of reusable workflows you can customize every time you use them. It's built around three things: a library of workflows (editable templates for tasks you do often), a Prompt Builder (assemble any prompt from building blocks like Role, Objective, and Output Format), and a Loop Builder (turn a normal prompt into a self-checking, autonomous prompt with goals and stop conditions).

What is this? — Full guide

The Personal AI Playbook is a system for reusing your best AI thinking, instead of rewriting prompts from scratch every time. It has four parts:

Workflow Library

Editable templates for tasks you do often — like spec'ing a feature or writing a build-in-public post. Each workflow has fill-in variables (dropdowns or text), a live-rendered prompt, an example, and best practices. Grouped into Build & Code, Startup & Strategy, and Build-in-Public Content.

Prompt Builder

For one-off prompts that don't fit an existing workflow. Add building blocks (Role, Objective, Context, Constraints, Reasoning Strategy, Output Format, Tone, Examples, Quality Checks), fill each in, and copy the assembled result.

Loop Builder

Wraps any prompt in a self-improving cycle: Goal, Evaluation Criteria, Improvement Strategy, Stop Conditions and Safety Rules. Use it when you want the AI to check and refine its own output automatically instead of stopping after one draft.

My Workflows & Favorites

Create new workflows, duplicate and edit library ones, or star favorites for quick access. Everything is saved to this browser via local storage — use Import/Export in the sidebar to back it up or move it to another device.
