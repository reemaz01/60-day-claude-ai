# 🤖 Autonomous Agent Studio

An AI-powered Autonomous Agent Studio that simulates a multi-agent software development workflow. The application demonstrates how specialized AI agents collaborate to plan, generate, evaluate, improve, and review Python code through an iterative feedback loop until predefined stopping conditions are met.

---

## 📌 Project Overview

Autonomous Agent Studio is designed to mimic a real autonomous software engineering team.

Instead of relying on a single AI response, multiple specialized agents work together to continuously improve generated code.

The workflow includes:

- Planning the implementation
- Generating Python code and tests
- Evaluating code quality
- Critiquing weaknesses
- Performing safety analysis
- Rewriting the implementation
- Recording memory between iterations
- Producing a final review

The application visualizes every stage of the autonomous workflow through an interactive dashboard.

# 🧠 Autonomous Agents

The application consists of eight specialized AI agents.

| Agent | Responsibility |
|---------|---------------|
| Planner | Creates implementation contract |
| Executor | Generates Python code |
| Evaluator | Scores implementation quality |
| Critic | Reviews weaknesses |
| Safety Monitor | Detects risky code |
| Improver | Refines implementation |
| Memory Manager | Stores iteration insights |
| Final Reviewer | Produces final assessment |

# 💡 Key Learnings

Building this project provided valuable insights into autonomous AI systems:

- Learned how multiple AI agents can collaborate to solve complex tasks.
- Understood iterative improvement using evaluation and feedback loops.
- Explored autonomous orchestration instead of single-response generation.
- Implemented dynamic stopping conditions based on performance improvements.
- Designed a workflow that separates planning, execution, evaluation, and review into specialized responsibilities.
- Improved understanding of agent memory, safety monitoring, and autonomous decision-making.
- Built a browser-based visualization to make complex AI workflows easy to understand.
