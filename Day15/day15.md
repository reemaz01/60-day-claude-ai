Day 15
Build a Personal Life Analysis Consultant

Vedic Astrology & Life Analysis Generator



The Vedic Astrology & Life Analysis Generator is an AI-powered system designed to create structured astrology reports based on user-provided birth details. The system generates detailed insights covering birth chart summaries, personality analysis, career potential, wealth prospects, relationship patterns, life forecasts, and recommended spiritual practices.

The project demonstrates advanced prompt engineering, structured report generation, information organization, and visual report design using generative AI.


Features

Birth Chart Summary

- Lagna (Ascendant) Overview
- Moon Sign Analysis
- Sun Sign Analysis
- Nakshatra & Pada Insights
- Planetary Placement Interpretation
- Key Strengths & Weaknesses

Life Pattern Analysis

- Core Personality Traits
- Childhood & Family Influences
- Relationship Tendencies
- Karmic Patterns
- Financial Behavior Analysis

Career & Wealth Analysis

- Career Suitability Assessment
- Job vs Business Potential
- Leadership Indicators
- Foreign Settlement Opportunities
- Wealth Accumulation Potential
- Property & Investment Prospects

Relationship Analysis

- Love vs Arranged Marriage Tendencies
- Marriage Timing Windows
- Spouse Characteristics
- Relationship Strengths & Risks

Forecasting Module

- Five-Year Life Forecast
- Career Outlook
- Financial Outlook
- Relationship Outlook
- Health Outlook

Recommendation Engine

- Spiritual Practices
- Mantras
- Donations
- Lifestyle Guidance
- Gemstone Recommendations (when applicable)



Workflow

1. Collect user birth details.
2. Process information using a structured astrology prompt.
3. Generate categorized interpretations.
4. Organize insights into report sections.
5. Create a visual infographic-style report.
6. Present findings in a user-friendly format.


Technologies Used

- Claude AI
- Prompt Engineering
- Generative AI
- Markdown Documentation
- Infographic Design
- Astrology Knowledge Frameworks

- Full Name
- Date of Birth
- Birth Time
- Birth Location
- Current City
- Relationship Status
- Profession
- User Concerns



Output

The system generates:

- Detailed Astrology Report

- Relationship Analysis
- Forecast Timeline
- Personalized Recommendations
- Visual Infographic Summary
