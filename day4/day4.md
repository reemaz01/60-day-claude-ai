Day 4 – Chain-of-Thought Prompting

Objective

Learn and apply Chain-of-Thought Prompting to generate a personalized career roadmap.

Prompt Used

You are an Elite AI Career Strategist.

Your goal is to build a personalized roadmap for me.

Before creating the roadmap, ask me ONLY these 4 questions:

Question 1
What is your current situation?
Examples:
• Student
• Working Professional
• Freelancer
• Founder
• Career Switcher

Question 2
What skills do you currently have?
Examples:
• Python
• Marketing
• Sales
• Design
• Web Development
• Data Analysis

Question 3
What is your target goal?
Examples:
• Get a job
• Land an internship
• Become a Data Scientist
• Become an AI Engineer
• Start a business
• Grow on LinkedIn

Question 4
What is your target timeline?
Examples:
• 3 months
• 6 months
• 1 year
• 2 years

After collecting all answers:

Think step by step.

1. Analyze my current position.
2. Identify strengths.
3. Identify skill gaps.
4. Identify the fastest path to the goal.
5. Recommend learning priorities.
6. Recommend projects.
7. Recommend networking strategy.
8. Create milestones.

Finally generate a visually structured ONE-PAGE roadmap.

The roadmap must contain:

🚀 Current Position
🎯 Target Goal
📈 Skill Gap Analysis
🛠 Recommended Learning Plan
💼 Suggested Projects
🌐 Networking Strategy
📅 Monthly Milestones
⚡ Immediate Next Actions

PDF DESIGN REQUIREMENTS:

• A4 Portrait Layout
• Professional consulting-report style
• Clean sections with visual hierarchy
• Tables wherever appropriate
• No overlapping text
• Use concise content
• Use visual dividers
• Maximum one page
• Export-ready PDF format
• Easy to screenshot and share on LinkedIn

End with:

Generated using Chain-of-Thought Reasoning

Insight

What struck me most about Claude's reasoning process was how it took a vague, overwhelming goal — "get an internship with zero skills" — and broke it into a concrete, week-by-week execution plan without making any assumptions about prior knowledge.

My key learning: Claude doesn't just dump information. It identifies skill gaps, prioritizes ruthlessly (only Python, Git, SQL — nothing else), and connects every learning topic to a tangible output (portfolio project, GitHub push, or LinkedIn update). That taught me that good career advice isn't about listing everything — it's about sequencing what matters first.

My main observation: Claude structures responses like a project manager, not a textbook. It includes timelines, resource links, networking strategies, and even cold email templates. The observation is that Claude treats the student's journey as the product — complete with milestones, deliverables, and a final "secure offer" goal. That's different from most generic advice, which just says "learn Python" and stops there.
