# 📰 Media Integrity Analyzer

An interactive browser-based application that teaches users how to recognize misinformation, clickbait, emotional manipulation, and media bias through hands-on analysis of realistic news headlines and social media posts.

---

## 📖 Overview

**Media Integrity Analyzer** is an educational web application that helps users build media literacy skills by identifying misleading headlines, emotional persuasion techniques, and audience-targeting strategies. Instead of simply explaining misinformation, the application lets users experience how manipulative content works before revealing the underlying tactics.

The project is built entirely with **HTML, CSS, and Vanilla JavaScript** and runs locally without any backend or external dependencies.

# 🖥️ Application Workflow

### 1. Welcome

- Introduction to media literacy
- Learn why misinformation spreads
- Begin interactive learning

---

### 2. Headline Detective

Users analyze realistic news headlines by:

- Choosing whether they would click
- Reading the full article
- Highlighting misleading phrases
- Comparing findings with expert analysis

Topics covered include:

- Clickbait
- Exaggeration
- Scientific misinformation
- Context omission
- Misleading wording

---

### 3. Emotion Detector

Users evaluate social media posts to identify emotional manipulation techniques.

Examples include:

- Fear
- Outrage
- Scarcity
- FOMO
- Guilt
- Social Proof
- Tribal Messaging

---

### 4. Media Integrity Dashboard

After completing both activities, users receive a personalized dashboard summarizing their analysis.

---

# 📊 Media Integrity Dashboard

The dashboard provides several educational metrics:

| Metric | Description |
|----------|-------------|
| Headline Accuracy | Evaluates whether the headline matches the supporting content |
| Source Reliability | Indicates the credibility and transparency of the information source |
| Emotional Manipulation | Measures the intensity of persuasive emotional language |
| Audience Targeting | Identifies how specifically the content is designed for a target audience |
| Integrity Score | Overall trustworthiness score based on all analyzed factors |

Additional insights include:

- Overall Integrity Score
- Biggest Red Flag
- Personalized Learning Summary
- Recommended Media Literacy Habits

# 📚 Key Learnings

Developing this project reinforced several important concepts:

- Interactive learning is more engaging than passive reading.
- Headlines often prioritize attention over accuracy.
- Emotional manipulation can strongly influence decision-making.
- Visual dashboards improve user understanding and retention.
- Progressive feedback helps users understand *why* content is misleading.
- Client-side web applications can deliver rich educational experiences without requiring a backend.
- Combining storytelling with interactive analysis creates a more effective media literacy tool.
